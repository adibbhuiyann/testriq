3
Review your answersCheck explanations and revisit your results from My results.
4
Install for offline useDeploy this project over HTTPS, then use your browser’s Add to Home Screen or Install app option. Open it once online so the app shell can be cached.

What is not in this release

100+ complete IELTS mocks, 4,000–6,000 expert-reviewed questions, full-length SAT/PTE test banks, licensed audio recordings, automated speaking or writing scoring, cloud accounts, synchronisation, leaderboards, video lessons and production backend are not implemented yet.

SAT practice is based on the current digital format: Reading and Writing plus Math. There is no optional essay or separate no-calculator section in this starter design.
